# AI Summary: RCAEval: A Benchmark for Root Cause Analysis of Microservice Systems with Telemetry Data

RCAEval addresses a practical gap in root cause analysis (RCA) research for microservice systems: the lack of a standard, open benchmark with sufficiently large and realistic telemetry data. The paper’s main objective is to make RCA evaluation more reproducible and comparable across studies by providing datasets and an evaluation environment that support multiple RCA settings, including metric-based, trace-based, and multi-source approaches.

Methodologically, the authors build three datasets—RE1, RE2, and RE3—covering 735 failure cases from three real microservice systems. RE1 contains only metrics and supports resource/network fault diagnosis; RE2 adds logs and traces for multi-source RCA across a broader set of fault types; and RE3 targets code-level faults using multi-source telemetry, with root causes inferred from stack traces, error logs, or response codes. They also release an evaluation framework with fifteen reproducible baselines and support for both coarse-grained and fine-grained RCA, along with efficiency and ranking-based metrics.

The paper’s key contribution is therefore not a new RCA algorithm, but a comprehensive benchmark infrastructure that enables fairer comparison of RCA methods under more realistic conditions. By open-sourcing the datasets and tools, RCAEval aims to help researchers and practitioners test methods on diverse failures and telemetry sources, and ultimately accelerate the development of more robust RCA techniques for microservice systems.
